# CliniQ Platform

Phase 1 technical foundation for the future CliniQ platform. It contains a Next.js web shell, a TypeScript REST API foundation, shared contracts/configuration, PostgreSQL migration tooling, and Docker development services.

The existing CliniQ web and Flutter projects are reference-only and are not part of this workspace.

See [development setup](docs/development-setup.md) and [foundation status](docs/foundation-status.md).
